Full-Stack AI-Assisted Coding Task

React + FastAPI · use Claude / Copilot as you normally would

Time budget15–20 min build + 10–15 min discussion
StackFastAPI (backend/) · React + Vite (frontend/)
ToolsClaude, Copilot, or any AI assistant you normally use
Use your AI tools freely. We're not evaluating whether you can type code without help — we're evaluating how you work with an assistant: what you accept, what you question, and whether you understand what ends up in your solution. Talk out loud as you go.

Setup

cd backend
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8010

# separate terminal
cd frontend
npm install
npm run dev

Confirm the app loads at http://localhost:5180 and shows a table of orders before you start the task.

The task

Add a live search/filter to the Orders list

Add a text input above the orders table that filters orders by item name as the user types (no submit button), querying the backend rather than filtering client-side. Specifically:

  • Add a query parameter to the GET /orders endpoint (e.g. ?q=) that filters orders whose item contains the search text (case-insensitive).
  • Wire the React input to call this endpoint as the user types, and update the table with the results.
  • Handle the loading and error states sensibly while typing.

You're free to prompt your AI assistant however you like — write your own prompt, ask it to plan first, iterate, whatever your normal workflow is.

What "done" looks like

  • Typing in the search box narrows the visible orders without a page reload
  • Clearing the box restores the full list
  • The app doesn't error out or show stale/wrong results in normal use

After you finish (or time runs out)

We'll spend the remaining time walking through your implementation together — including anything the AI generated that you kept, changed, or discarded. Be ready to explain how it behaves under conditions you may not have explicitly tested (e.g. typing quickly, slow network, empty input).
